# Files that work with Splash Canvas

No account. Drop these onto the window, or click **Open files**. Live looks (Matrix, kaleidoscope, fire…) need **no files**. Halloween ideas can also run with **built-in patterns**.

## Best drops

| File | Why it works |
|------|----------------|
| **PNG / WebP / JPEG / GIF** with a **black background** | Turn on **Omit black** — only the spooky bits hit the house |
| **MP4 / WebM** loops (muted, looping) | Fire, smoke, bats, flickering faces. Keep them short and dark-plated |
| **Vertical still** (9:16 or door-shaped) | Front door, tombstone, column |
| **1:1 still** | Pumpkin, round window, moon |
| **16:9 still or video** | Garage door, facade |
| **UV-mapped OBJ** | Real geometry from Blender. UVs are required. Premade shapes cover most Halloween jobs without an OBJ |
| **splash.json + the OBJ it names** | Splash / Blender Splash-addon export. Drop both together (or a folder) |
| **Folder of mixed files** | JSON + OBJ + media in one drop |

Built-in starter files (MIT, in this app):

- `samples/grid_wall.obj` — 8×6 UV wall
- `samples/starter.json` — tiny Splash-style graph
- Generated Halloween looks (pumpkin, ghost, bats, web, moon, eyes, slime, candles, veins, tomb, fog, window, door)
- Live motion looks (Matrix rain, kaleidoscope orbs, fire, rain, snow, star tunnel, swarm, scanlines, portal, glitch, aurora, Game of Life, vortex, pulse, ink, lattice, waveform, mosaic, bloom, tide, clock)

Do **not** copy Splash’s GPLv3 C++ or its `wall_corner.obj` into this repo. Speak the same JSON/OBJ graph; keep original meshes MIT or your own Blender export.

## Where to get loops (royalty-free, you download them)

Search Mixkit, Pixabay, or NASA for: `bats loop`, `fire loop black background`, `smoke loop`, `full moon`, `ocean loop`, `fireplace loop`. Prefer **black plate** footage so Omit black punches it onto architecture. Then turn **Kaleido slices** up if you want the HeavyM/Resolume fold.

## Motion idea generator

In the app: **Ideas** (or `I`). **Matrix** / `M` plays the rain.

1. The studio starts on **The Matrix**. **Use** on any card loads a shape + live look or spooky still.
2. **Kaleido slices** + **Spin** fold Matrix, a photo, or a dropped video into a kaleidoscope.
3. Click **Riff this** to keep some of the idea and swap the rest (where / haunt / shape / live look).
4. Type your own spark (`code on the door`, `kaleidoscope in the garage`) and **Riff from this**.
5. **Surprise me** rolls a full random motion.

Filters: Featured · All (200+) · Matrix · Kaleido · Video · Halloween.

That is how you generate ideas from ideas: each card is a seed, riff mutates it, your text is another seed.
